# Local portfolio fonts

These files are self-hosted so the portfolio does not depend on Google Fonts at runtime.

- DM Sans variable, latin subset: Google Fonts `dmsans/v17`
- DM Serif Display regular and italic, latin subsets: Google Fonts `dmserifdisplay/v17`
- Licenses: SIL Open Font License files are retained in `assets/itch-profile/source/fonts/`.
