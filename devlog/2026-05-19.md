# 2026-05-19 — Day 0: scaffold

First commit. Site stands up locally.

## What's in

- Astro 5.18 + Tailwind v4 + React 19 + Framer Motion 12.
- Content collection schema in `src/content.config.ts` (Zod-validated frontmatter, `depth: deep | light` controls whether a project gets its own page or a modal).
- Pages: `/`, `/about`, `/projects`, `/projects/[slug]`, `/intern`, `/legacy`.
- Role-tag filter + animated grid in `ProjectGrid.tsx` (the only React island; everything else is static HTML).
- 8 project markdown files seeded:
  - **deep**: Right-Click to Activate Translator, The Birthday Party, Heart-Keys, Gugugaga Penguin
  - **light**: Devil-Cops & Androids, Space Bar Porter, Night at the 8th Warehouse, Hashmon
- *Kirakira Rakugo Shojo!* kept out (no markdown file yet — will stay `hidden: true` if added).
- Design tokens: dark Sawdust-inspired palette (`#0b0b0d` bg / `#f4efe6` ink / `#e07a3c` accent), Fraunces + Inter + JetBrains.
- SVG grain overlay on `body.grain` for paper-feel.

## Decisions

- **Apex `hiddenblade.net` → new portfolio** (Cloudflare Pages, when ready).
- **Old WordPress → `archive.hiddenblade.net`**, frozen as literary archive. `/legacy` page links into it with a "Before games, there were words." transition.
- Tailwind v4 CSS-first config via `@theme` block — no `tailwind.config.js`.
- Single React island strategy: keep ship surface tiny, only ship JS where animation/state is needed.

## What worked / didn't

- ❌ `npm install` in PowerShell — blocked by execution policy on `npm.ps1`.
- ✅ `npm.cmd install` works around it. Saved to user memory.
- ❌ Default npm registry hung for ~10 min on a fresh tree.
- ✅ `--registry=https://registry.npmmirror.com` finished in 3 min (545 packages).
- ✅ `npm.cmd run dev` → `astro v5.18.1 ready in 1128 ms`, no errors, content collection synced clean.
