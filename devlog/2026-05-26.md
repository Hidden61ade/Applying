# 2026-05-26 — ACI groundwork: The Herder and the Hunter

Started a new project track. The one the portfolio doesn't have yet: a game where the second player is not human.

## What's in

- New project page drafted at [src/content/projects/herder-and-hunter.md](../src/content/projects/herder-and-hunter.md), `hidden: true` until V1 demo is on tape.
- Two mandatory-reading papers ingested into `ACIProject/`:
  - Noz & An, *Cat Cat Revolution* (CHI 2011) — interspecies tablet game, 7-pair pilot, frames the cat as participant. Loop never closes (no kill step).
  - Payne, Kleinberger & Hirskyj-Douglas, *Look What the Cat Tapped In* (ACI 2025) — MewTube, 5-month cat-café study, 28 humans / 16 cats. Tablet condition produced *weaker* perceived bonding than traditional toys. Responsiveness gap is the headline.
- Both PDFs extracted to plain text via `_extract.py` (pypdf) for grep-ability later.
- Design space mapped: **concurrent asymmetric co-op** is the open axis between CCR (sequential / shared target) and MewTube (passive viewing).

## The design (V1)

- Human draws scent corridors with a finger; prey particles funnel along the path to a hunting zone.
- Cat pounces inside the zone. Touch-area thresholding separates paw input from finger input on the same screen.
- Bluetooth treat dispenser closes the predatory chain after N pounces. This is the part neither precedent paper does.
- Visuals: blue/yellow only (Pons & Jaen). Session length capped around 150s (Hall habituation).
- Ethics baseline: Mancini's ACI Manifesto. "Cat refused to play" is a reportable outcome.

## What worked / didn't

- ❌ `pip install pypdf` over the system proxy — SSL handshake failure on pypi.org and tsinghua mirror both.
- ✅ Same install with `HTTP_PROXY=""; HTTPS_PROXY=""; pip install --user pypdf` — finished clean. Logged to user memory.
- ✅ pypdf extracted both PDFs cleanly; figure captions survived, references intact.
- ❌ First attempt piped `python _extract.py ... > paper.txt` from PowerShell — output came out UTF-16. Switched to writing the file from inside Python (`open(..., encoding="utf-8")`).
