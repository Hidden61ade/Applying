## Context

A language-driven puzzle game built around the idea that interpretation **is** gameplay. Players translate a constructed hieroglyphic language to manipulate memory fragments, items, and spatial relations.

## My Role

- Designed the systemic relationship between Memory · Backpack · Map so each puzzle is a sentence the player rewrites.
- Wrote the narrative bible and authored core puzzle scripts.
- Owned the conlang-to-mechanic translation rules.

## Outcome

- **Best Puzzle Game** at the 2024 China University Student Game Award.
- Demo shipped on Steam during the application cycle.

## Reflection

This is where I learned that mechanics can be a grammar. The system constrains *what can be said*; the player decides *what is said*. That is a kind of co-authorship I keep chasing.
